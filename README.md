# CampusBite 🍱

CampusBite is a smart campus canteen ordering and locker pickup
UI/UX prototype designed to reduce waiting time for students.

## 🚀 Live Prototype

https://campusbite-canteen-smart-locker-pickup.ai.studio

## 🎯 Problem

Students often spend significant time waiting in crowded campus
canteens to collect their food.

## 💡 Solution

CampusBite allows students to:
- Browse the canteen menu
- Place food orders
- Receive an order/locker number
- Pick up food from a smart locker
- Track their order status
